# 审题雷达 · 纸质审题训练卷生成器（math/）

## 产品定义

孩子没有设备，工具形态为**家长单页操作：选内容 → 生成 → 打印 A4 → 孩子纸上练**。训练核心是「**一圈二列三桥四式**」四步审题法，专项解决「不会从题目里找条件」：

- **一圈**：把题目里有用的数字和关键词圈出来（题目印宽松行距，供笔圈）
- **二列**：把条件填进「已知 / 要求」表格（对齐苏教版四上第五单元列表策略）
- **三桥**：填「要求 X，先要算出 ___」（两步题的中间量训练）
- **四式**：分步列式

卷尾附**孩子自查讲评页**：步骤拆细、字大，最终答案统一放每题右下角小字加边框（做完才翻得到），页脚「今天我对 ___ 题」计星自查。讲评页标记语义全部用加粗/下划线/删除线/序号圈表达，**不依赖彩色打印**。

**闭环**：历史卷里家长勾「错题」→ 一键生成**变式卷**（同模板换数字重出），错题不是抄一遍而是「换个数再做对一次」。

## 题库范围（已学单元，30 个模板）

| 单元 tag | 覆盖内容 | 模板数 |
|---|---|---|
| division | 除法应用·归一归总、单价总价 | 8 |
| strategy | 列表策略·行程、搭配、方案 | 8 |
| volume | 升和毫升·换算（隐藏条件 1L=1000mL）与应用 | 5 |
| average | 平均数 | 5 |
| （跨单元）多余条件型 | 题干埋一个用不上的数字 | 4（含在上面配额） |
| （跨单元）补条件型 | 题目故意缺条件，三选一补上 | 4（含在上面配额） |

难度分 1/2/3 级；混合运算单元留 schema 支持、v1 不出题。

## 数据契约（核心 schema）

**模板**（problems.json 逐字段）：
```json
{
  "id": "T012", "unit": "division", "type": "standard",
  "skill": ["condition", "bridge"], "level": 2,
  "story": "超市运来{n1}箱酸奶，每箱{n2}盒，平均分装到{n3}个货架上。",
  "question": "每个货架放多少盒？",
  "params": { "n1": [3, 9, 1], "n2": [24, 60, 6], "n3": [3, 6, 1] },
  "calc": { "total": "{n1}*{n2}", "ans": "{total}/{n3}" },
  "constraints": ["{total} % {n3} == 0", "{ans} >= 10"],
  "segments": [
    { "t": "超市运来{n1}箱酸奶", "type": "condition" },
    { "t": "，每箱{n2}盒", "type": "condition" },
    { "t": "，上架后平均分装到{n3}个货架", "type": "condition" },
    { "t": "上", "type": "plain" }
  ],
  "table": { "known": ["{n1} 箱", "每箱 {n2} 盒", "{n3} 个货架"], "ask": "每个货架 ？ 盒" },
  "bridge": { "ask": "要求每个货架放多少盒，先要算出",
              "choices": ["酸奶总盒数", "箱数", "货架层数"], "answer": 0 },
  "steps": ["{n1} × {n2} = {total}（盒）", "{total} ÷ {n3} = {ans}（盒）"],
  "answer": "{ans} 盒",
  "tip": "「平均分装到」= 总数 ÷ 份数，先求总数再求每份。"
}
```
- `type`：standard / distractor（segments 含 `distractor` 段）/ supply（缺条件三选一）
- **约束 DSL**：极简表达式（变量 + `+ - * / %` + `== != > < >= <=` + 括号），手写递归下降求值器约 50 行，不用 eval；实例化参数最多重试 50 次，失败换下一模板，保证不死循环

**Store 契约**（localStorage `math.` 前缀，get 一律默认值合并 + 枚举校验）：
- `math.config`：`{ units:[...], level:"mix", scaffold:"A", count:5, withReview:true }`
- `math.sheets`：`[{ id, no(卷号), date, config, problems:[{tplId, params, story, question, answer, marked}] }]`（存文本快照，题库更新不影响旧卷重印），上限 30 卷 FIFO
- `math.no`：卷号计数器

## generator.js API（纯函数）

- `make(config, templates) → sheet`：按 units+level 过滤 → 洗牌抽 count 个不重复模板 → 逐题实例化
- `instantiate(tpl) → instance`：随机参数（min/max/step）→ 算 calc → 验 constraints
- `evalExpr(expr, scope)`：约束求值器，导出供批量自检

## index.html 页面（沿用 dictation/parent.html 编号区块模式）

1. **练什么**：单元 chips 多选 + 难度 seg（基础/进阶/混合）
2. **怎么练**：脚手架 seg（A 全程扶：表格画好行+搭桥选择题+分步算式线 / B 半扶：空表格+填空 / C 放手：纯题目+作答区）+ 题量 counter（3-10）+ 含讲评页 switch
3. **出卷**：生成 → 屏幕预览（A4 比例渲染，与打印共用渲染函数）→ 打印 / 换一批题
4. **历史与错题**：卷列表 → 点开只读预览 + 每题「错」标记 → 「用错题出变式卷」

## 打印实现（复用 wrongbook 骨架，去掉图片生命周期）

- `#print-sheet { display:none }`；`@media print { @page { size:A4 portrait; margin:12mm } body>*:not(#print-sheet){display:none!important} }`
- 题块 `break-inside:avoid`（双写 page-break-inside）；题目行高 ~2.2em 供圈划；A/B 级每页 3 题、C 级 4 题
- 讲评页 `page-break-before:always`，页首自查引导语 + 页脚计星栏
- 卷首页眉：第 N 卷 · 日期 · 难度 + 四步法口诀条
- iPhone UA 检测禁打印 + 「请在电脑端打开」提示（抄 wrongbook）

## 实施顺序

1. `design/PRD.md` + `docs/架构设计-v1.md`（定契约）
2. `data/problems.json`：30 模板逐题打磨（内容质量是本工具的核心资产，每题含 segments 标注、表格、搭桥、分步、审题提示）
3. `js/generator.js` + 控制台批量自检（每模板实例化 100 次：约束全过、答案整数合理、无 NaN）
4. `js/store.js`
5. `index.html`（配置 → 预览 → 打印 → 历史变式）
6. 根卡片 + .assetsignore
7. 验证：A/B/C 三级 × 含/不含讲评页 × 3 题/10 题极端卷的打印预览检查（分页、留白、黑白可读性）

## 明确不做（v1）

- 孩子端页面 / TTS 听题（孩子无设备）
- 混合运算单元出题（未学到，schema 已预留）
- 对比题组（「每箱40本」vs「共40本」一字之差题型，v2 再加）
- 图形题（观察物体/垂线平行线不适合纸面审题训练形态）
