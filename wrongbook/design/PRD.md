# 错题本 · PRD

版本：v0.1（2026-10-21） · 负责人：产品UI · 状态：待评审

## 1. 背景与目标

- 孩子测验/考试卷上的错题，家长想留下来让孩子重做。手抄题目费时费力，拍整张照片存档又没法按题检索、也没法排版打印。
- 目标：拍一份试卷 → 手指框选出每道错题 → 自动归入学科/测验/标签 → 需要时勾选打印成 A4 重做卷。

## 2. 用户与场景

| 角色 | 诉求 |
| --- | --- |
| 家长（录入者/管理者） | 拍照框选错题、填写学科与所属测验、给错题打标签、定期打印成卷 |
| 学生（使用者） | 拿到打印的重做卷，重新作答 |

形态：网页版 H5；录入以手机为主（拍照方便），打印在电脑浏览器操作。无需登录，数据存本机。

## 3. 功能需求

### 3.1 错题录入（P0）

1. 拍照或从相册选图：`<input type="file" accept="image/*" capture="environment">` 调起相机；电脑端即文件选择。一次拍照可连续框选多道错题。
2. 框选：整图显示在画布上，手指/鼠标拖出矩形选区，实时预览裁剪结果，可重框。
3. 保存表单：学科（下拉，可管理自定义学科）、所属测验/试卷名称（文本，自动记忆历史输入供补全）、标签（多个，可增删，自动记忆历史标签）、备注（可选）。
4. 日期自动填充为当天（可改）。
5. 连续录入：保存一道后不退出拍照页，可继续框选下一道；提供「完成」返回列表。

### 3.2 错题本列表（P0）

1. 卡片式列表：缩略图 + 学科 + 测验名 + 日期 + 标签。
2. 筛选：按学科、按测验（随学科联动）、按标签、按日期区间。
3. 多选：卡片点击进入详情/大图；提供选择模式供打印勾选（也支持筛选后直接「打印当前筛选结果」）。
4. 详情操作：查看原图大图、改学科/标签/备注、删除。
5. 「已掌握」标记（P1）：标记后默认不出现在打印列表，可切换显示。

### 3.3 打印（P0）

1. 从勾选/筛选结果生成 A4 竖版打印预览：每页 N 题（1 / 2 / 4，默认 2），每题含题号、图片、学科·测验·日期、标签。
2. 重做留白设置：每题下方留白高度（无 / 3cm / 6cm / 9cm，默认 3cm），用于手写重做。
3. 调起 `window.print()`，走系统打印对话框选打印机。
4. iPhone Safari 不支持 window.print()，检测后提示「请在电脑端打开打印」。

### 3.4 学科与数据管理（P0）

1. 学科管理：内置 语文 / 数学 / 英语，可增删改自定义学科。
2. 数据备份：一键导出 JSON（含图片 base64）下载到本地；支持导入恢复。首次进入若数据非空，提示用户备份。

### 3.5 后续版本

- P1：OCR 文字检索错题、已掌握标记、打印历史。
- P2：多端同步（接轻后端，Cloudflare D1/R2）。

## 4. 非功能需求

- 兼容：手机 Safari / Chrome（拍照、框选）；桌面 Chrome / Edge / Safari（打印）。
- 存储：图片裁片存 IndexedDB（配额远大于 localStorage），元数据与设置随图片同库/小键存 localStorage；读写失败要降级提示而非静默丢数据。
- 体积：裁片输出 JPEG q≈0.85、长边 ≤1600px，单题约 50–200KB；整份试卷原图不入库，框选后丢弃。
- 字号与触控：录入和列表以手机单手操作为目标，按钮 ≥44px。
- 渲染安全：用户输入（测验名、标签、备注）一律 textContent 渲染，禁 innerHTML 拼接。

## 5. 关键交互流程

录入：拍照 → 框选第 1 题 → 填学科/测验/标签（日期自动）→ 保存 → 继续框选第 2 题 → … → 完成返回列表
打印：列表筛选/勾选 → 打印预览（每页题数、留白）→ window.print() → 系统打印对话框

## 6. 边界与暂不做

- 不做登录/多端同步（P2 再说）
- 不做手写批改 / 自动识别错题（框选是手动指定）
- 不做 OCR（P1）
- 不直连打印机（WebUSB/ESC-POS 不适合 A4），走系统打印对话框
- 仅 H5，不做 App / 小程序

## 7. 待确认问题

2. 打印是否需要"答案页"（把错题连同正解一起打印）？当前方案：不做，错题本里只存题目裁片。
3. 是否需要在打印时隐藏标签/日期等元信息？当前方案：打印设置里提供开关。
