# 错题本 · 架构设计 v1

版本：v1（2026-10-21） · 负责人：架构后端 · 状态：待评审

## 1. 总体结论

**P0 不做服务端，纯前端 H5，本地 IndexedDB 存图片 + localStorage 存小配置。**

理由：

- 数据全部产生和消耗在本机（拍照、打印），无登录态，没有任何需要服务端承载的写操作。
- 错题图片是二进制大对象，localStorage（约 5MB）不够，IndexedDB 浏览器一般允许数百 MB，且支持 Blob 原生存储，不用 base64 膨胀。
- 部署与默写工具一致：纯静态文件 + Cloudflare Pages，零后端成本。
- P2 多端同步时数据模型不变，只把 Store 实现换成 HTTP 客户端，前端业务代码零改动。

## 2. 技术选型

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 形态 | 静态 H5，两个页面：`index.html`（错题本列表+打印）、`capture.html`（拍照+框选+录入） | 与 dictation 相同的"入口扁平化"惯例，不加额外落地页 |
| 存储 | IndexedDB（图片 Blob + 题目元数据）；localStorage 只存学科列表、打印设置、录入历史记忆 | 见第 4、5 节 |
| 拍照 | `<input type="file" accept="image/*" capture="environment">` | 一行调起相机，不写 getUserMedia 预览 |
| 框选裁图 | `<canvas>` + Pointer Events 拖框；`createImageBitmap(blob, { imageOrientation: "from-image" })` 修正 EXIF 方向 | 输出 JPEG q≈0.85，长边 ≤1600px |
| 打印 | `window.print()` + `@media print` 拼版样式 | A4 竖版，见第 6 节 |
| 构建 | 无构建，原生 HTML/JS | 与 dictation 一致 |

## 3. 数据模型

### 3.1 题目元数据（IndexedDB store `questions`）

```js
{
  id: "q_1729497600000_a1b2c3",   // "q_" + createdAt + 随机后缀
  subject: "数学",                 // 学科名（自由文本，来自学科列表）
  exam: "四年级上册 第3单元测验",   // 所属测验/试卷名
  tags: ["计算错误", "审题不清"],   // 标签数组
  date: "2026-10-21",             // 测验日期（默认当天，可改）
  note: "",                        // 备注（可选）
  createdAt: 1729497600000,
  imageId: "img_1729497600000_a1b2c3"  // 对应 images store 的键
}
```

### 3.2 图片（IndexedDB store `images`）

键 `imageId`，值 `{ blob: Blob, width, height, size }`。裁片为 JPEG Blob；元数据存尺寸便于列表缩略图与打印拼版不用解码。

### 3.3 本地小配置（localStorage，前缀 `wb.`）

| 键 | 内容 |
| --- | --- |
| `wb.subjects` | 学科列表：`["语文","数学","英语", ...自定义]`，默认内置前三 |
| `wb.print.settings` | `{ perPage: 1\|2\|4, blankCm: 0\|3\|6\|9, showTags: bool, showMeta: bool }`，默认 `{ perPage: 2, blankCm: 3, showTags: true, showMeta: true }` |
| `wb.hints.exams` | 历史测验名去重数组（最多 50 条，供录入表单 datalist 补全） |
| `wb.hints.tags` | 历史标签去重数组（最多 100 条） |

## 4. IndexedDB 契约

数据库名 `child-tool-wrongbook`，版本 1，两个 object store：`questions`（keyPath `id`，索引 `byDate` on `date`、`bySubject` on `subject`）、`images`（keyPath `imageId`）。

- 打开失败（隐私模式/禁用时）：降级为内存态并在页面顶部显示常驻黄色提示条「本地存储不可用，数据关闭页面后将丢失，请及时导出备份」。
- 启动时调用 `navigator.storage.persist()` 申请持久化，降低被浏览器自动清理的概率。
- 所有读写返回 Promise；`Store` 层统一捕获异常转为 `{ ok: false, error }` 由 UI 提示，不允许静默失败。

## 5. 前端数据访问层（接口契约）

前端不散写 IndexedDB / localStorage，统一走 `js/store.js`（命名空间 `Store`）：

```js
// 学科
Store.subjects.get()                // => string[]
Store.subjects.add(name)            // => { ok }
Store.subjects.remove(name)         // => { ok }（该学科下题目数 >0 时拒绝并返回 { ok:false, reason:"in-use" }）

// 题目（均返回 Promise）
Store.questions.add({ subject, exam, tags, date, note?, imageBlob, width, height })
                                    // => { ok, meta }
Store.questions.list(filter?)       // => { ok, metas[] }  filter: { subject?, exam?, tag?, from?, to? }，结果按 date desc, createdAt desc
Store.questions.get(id)             // => { ok, meta, blob }
Store.questions.update(id, partial) // 仅允许改 meta 字段（subject/exam/tags/date/note）
Store.questions.remove(id)          // meta 与图片一并删

// 打印与筛选辅助
Store.questions.distinctExams(subject?)   // => string[]  供筛选下拉
Store.questions.distinctTags(subject?)    // => string[]

// 录入历史记忆（localStorage）
Store.hints.exams() / Store.hints.addExam(name)
Store.hints.tags()  / Store.hints.addTags(names[])

// 备份
Store.backup.export()   // => 触发 JSON 文件下载（questions + images base64 + subjects）
Store.backup.import(file) // => 校验后全量覆盖导入（导入前自动导出一份"导入前备份"）

// 打印设置
Store.printSettings.get() / Store.printSettings.set(partial)
```

## 6. 打印拼版设计

- 列表页内嵌一个仅打印时可见的 `#print-sheet` 区域：`@media screen` 下 `display:none`，`@media print` 下页面其余元素 `display:none`、打印区 `display:block`。
- `@page { size: A4 portrait; margin: 12mm; }`。
- 每题一个 `.pq` 卡片：题号 + 图片（`max-width: 100%`，按 perPage 分栏：1题/页全宽、2题/页、4题/页即 2×2 网格）+ 元信息行（学科 · 测验 · 日期，受 showMeta 控制）+ 标签行（受 showTags 控制）+ 留白区（高度 blankCm，用 `break-inside: avoid` 防跨页截断）。
- 图片高度兜底：单图过高时 `max-height` 限制（约 22cm / 12cm / 8cm，对应每页 1/2/4 题），超出等比缩放。
- 调用 `window.print()` 前先把选中题目的 blob 解码为 objectURL 填入打印区，打印对话框关闭后（`afterprint` 事件）统一 revokeObjectURL。
- iPhone Safari 不支持打印：检测 `/iP(hone|od)/` 且非 iPad 时，打印按钮替换为提示「打印请在电脑端打开本页」。

## 7. 边界与安全

- 无网络请求即无注入面；测验名、标签、备注等用户输入渲染一律 `textContent`。
- localStorage 读写包 try/catch 降级内存态（与 dictation store.js 同款手法）。
- IndexedDB 不可用降级内存态 + 常驻提示条（见 §4）。
- 导入备份时校验 `app == "child-tool/wrongbook"` 与 `schemaVersion` 兼容（只接受 `1.x`），图片 base64 解码失败跳过该题并在结果里计数报告。
- 删除学科、删除题目均为即时生效且不可撤销（P1 可加回收站），删除前用原生 `confirm()` 确认。
