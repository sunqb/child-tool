# 默写小工具 · PRD

版本：v0.1（2026-10-13） · 负责人：产品UI · 状态：待评审

## 1. 背景与目标

- 家长给小学/初中孩子布置听写默写（语文词语、英语单词）是个高频刚需，但家长自己念词费时间、发音不准，孩子自己默写没人报词。
- 目标：家长 1 分钟配置好词库，孩子打开就能听写，全程语音播报，无需家长陪同。

## 2. 用户与场景

| 角色 | 诉求 |
| --- | --- |
| 家长（设置者） | 按教材版本/年级/学科选词库，配置播报参数，发起默写 |
| 学生（使用者） | 点开即听写，听到词写答案，错了能重听，结束看成绩 |

形态：网页版 H5，手机浏览器使用；家长模式和学生模式两个入口，无需登录（本地存储配置）。

## 3. 功能需求

### 3.1 家长设置页（P0）

1. 词库选择：教材版本（人教版/部编版/北师大版/苏教版/外研版…）→ 年级（1–9 年级）→ 学科（语文/英语）→ 单元（如"语文二年级上册 第3单元 词语表"）。
2. 播报设置：语速（慢/标准/快）、每词重复次数（1–3 次）、词间隔秒数（3/5/8 秒）、英语是否附中文释义。
3. 范围设置：默写全部词或自定义前 N 个 / 仅错词本。
4. 发起默写：生成"学生入口"（本机直接进入 / 短口令或二维码给另一台设备）。
5. 错词本：自动收集默写错误词，可单独重默。

### 3.2 学生默写页（P0）

1. 听写主流程：语音播报当前词（自动 + 手动"再听一遍"）→ 输入/手写答案 → 提交 → 自动播下一个词；顶部大字显示进度（3/20）。
2. 播报可暂停/继续，可调速。
3. 结束页：得分、对错列表（错词标红）、加入错词本、一键重默错词。
4. 中途退出可恢复（本地记录进度）。

### 3.3 词库数据（P1，需架构后端支持）

- 内置各版本教材同步词库（语文词语表、英语单词表），按 版本/年级/学科/单元 四级组织。
- 家长可自建自定义词库（手动录入/粘贴导入，一行一词）。

## 4. 非功能需求

- 语音：浏览器 Web Speech API（speechSynthesis）中文播报，零成本起步；后续可换云端 TTS 提升音质。
- 数据：无登录态，词库和进度存 localStorage；自定义词库需要导出/分享时再接后端（P2）。
- 兼容：手机 Safari / Chrome，需用户首次点击后才允许发声（浏览器自动播放限制）。
- 字号：学生页面大字号、高对比，孩子独立操作友好。

## 5. 关键交互流程

家长：选版本 → 选年级 → 选学科 → 选单元 → 调播报 → 「开始听写」→ 交给孩子
学生：进入听写 → 听词 → 书写 → 提交 → 听下一词 → … → 成绩单 → 重默错词

## 6. 边界与暂不做

- 不做登录/多端同步（P2 再说）
- 不做拍照批改手写（P2）
- 不做 App，仅 H5
