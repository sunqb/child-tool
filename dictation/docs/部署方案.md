# 听写工具 · 部署方案

纯静态站点，无后端、无构建步骤、无密钥。总体积约 27MB（含预生成播报音频 26MB / 2159 个 mp3，`tools/generate_audio.py` 可增量重跑）。

## 一、部署要求

| 项 | 说明 |
|---|---|
| 运行环境 | 任意装有 Python 3 的机器（macOS/Linux 自带；Windows 装 Python 后同样可用） |
| 对外依赖 | 内置词库音频已预生成在 `audio/` 目录（`tools/generate_audio.py` 产物），默认「在线语音」模式下内置词播报**零网络依赖**；仅自建词库新词走 LibreTTS 在线合成，失败自动降级浏览器内置语音 |
| 必须 HTTP 访问 | `wordbank.json` 走 `fetch()`，直接双击 html（file://）打不开词库，会降级到内置示范词库 |
| 数据持久化 | 全部在浏览器 localStorage，换浏览器/清缓存会丢，服务端无状态 |

## 二、部署步骤（本地 / 内网）

1. 把整个 `dictation-tool/` 目录拷贝到目标机器任意位置（内网服务器建议放 `/opt/dictation-tool/`）。
2. 赋予脚本执行权限并启动：

```bash
chmod +x deploy.sh
./deploy.sh            # 仅本机: http://127.0.0.1:8080
./deploy.sh 8080 0.0.0.0   # 内网共享: http://<本机IP>:8080，手机/其他电脑同网段可访问
```

脚本自带 `Cache-Control: no-cache` 响应头，用户普通刷新即拿最新版本，无需强刷。

3. 健康检查（脚本启动前已自检文件齐全和 JSON 合法，启动后可再验证）：

```bash
curl -sf http://127.0.0.1:8080/parent.html        # 家长页
curl -sf http://127.0.0.1:8080/data/wordbank.json # 词库（应返回 264K 左右 JSON）
```

浏览器打开后家长页走完「学科 → 年级 → 版本 → 单元」并发起一次听写，即验证通过。

## 三、上线前清单

- [ ] `data/wordbank.json` 为正式数据（当前：1712 词 / 160 单元 / 20 册）
- [ ] 前端缺陷 1（自建词库英文词判分）与建议 2（0 词会话续默提示）已修复并通过测试复测
- [ ] 用 agent-browser 或真机对部署后的 URL 跑一遍：发起听写 → 判分 → 成绩单 → 错词本

## 四、回滚

静态站点回滚 = 换回旧目录 + 重启服务：

```bash
# 升级前先备份
cp -r dictation-tool dictation-tool.bak-<日期>
# 新版本有问题时
rm -rf dictation-tool && mv dictation-tool.bak-<日期> dictation-tool
# 重启 deploy.sh 即完成回滚
```

因数据都在各设备浏览器 localStorage，服务端回滚不影响用户已存的词库/错词本。

> 注意：用裸 `python3 -m http.server` 起的服务（不带 no-cache 头）会让浏览器缓存旧页面，用户升级后可能看到旧版。老入口若如此启动，请告知用户强刷一次（Cmd/Ctrl+Shift+R），或用新版 deploy.sh 重启服务。

## 五、内网长期运行的可选增强（非必需）

- 用 `systemd` / `launchd` 把 `deploy.sh` 注册为常驻服务，断线自动拉起
- 前面加 nginx 做 80 端口转发和 gzip（词库 JSON 压完约 60K，首屏更快）
- 注意：**不要**给这个目录加访问鉴权以外的写接口——它是纯静态，任何"上传/同步"需求都应走新版本部署而非服务端接口
