# 默写小工具 · 架构设计 v1

版本：v1（2026-10-13） · 负责人：架构后端 · 状态：待 Chief 评审

## 1. 总体结论

**P0 不做服务端，纯前端 H5 + 静态 JSON 词库。**

理由：
- PRD 明确无登录态，配置和进度都在本机（localStorage），没有任何需要服务端承载的写操作。
- 词库是只读数据，天然适合静态 JSON 随站点部署，零后端成本、加载快（gzip 后一个全量词库 < 200KB 量级）。
- 语音播报走浏览器 speechSynthesis，不依赖后端。
- P2 出现的多端同步 / 自定义词库分享，再加后端（BaaS 或轻量 Node 服务）不迟，届时数据模型不变，只是存储位置迁移。

## 2. 技术选型

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 形态 | 静态 H5（两个入口：`parent.html` 家长设置 / `kid.html` 学生默写） | 手机 Safari / Chrome |
| 词库 | 静态 JSON，按 版本/年级/学科/单元 四级组织 | 见 data/wordbank.schema.json |
| 存储 | localStorage | 见第 4 节键位约定 |
| 语音 | Web Speech API（speechSynthesis） | 首次点击后发声；预留 TTS 适配层，可平滑换云端 TTS |
| 构建 | 无构建，原生 HTML/JS | 体量小；后续复杂了再上 Vite |

## 3. 词库数据模型

四级结构：`version → grade → subject → unit → words[]`

- 每个词条：`{ word, tip? }`（语文：word + tip 释义）；`{ word, meaning?, example? }`（英语：word + meaning 中文释义 + 可选例句）。
- 学科用固定枚举 `chinese / english`，播报逻辑据此分支。
- 数据文件：`data/wordbank.json`（正式数据）；`data/wordbank.sample.json` 是可运行的示意数据。
- 校验：JSON 需通过 `data/wordbank.schema.json`（JSON Schema draft-07），CI/交付前跑一遍校验即可。

**词库数据来源（回应 PRD 待确认问题 1）**：起步为人工整理的内置 JSON。网上没有稳定授权的现成词库 API，且各版本教材词语表有版权口径问题，人工维护 JSON 最可控；后续词库扩充由家长需求驱动逐版本补录。

## 4. 本地存储契约（给前端的"接口"）

统一前缀 `dict.`。所有 value 均为 JSON 字符串。

| 键 | 内容 | 写入方 | 读取方 |
| --- | --- | --- | --- |
| `dict.parent.config` | 家长播报设置：`{ speed: 0.6|0.9|1.2, repeat: 1|2|3, gapSec: 3|5|8, withMeaning: boolean }` | 家长页 | 学生页 |
| `dict.parent.selection` | 词库选择：`{ versionId, gradeId, subjectId, unitId }`（UI 选择顺序为 学科→年级→版本→单元，版本按学科默认带出、可切换；存储字段不变） | 家长页 | 学生页 |
| `dict.session.current` | 进行中的默写会话：`{ words: WordEntry[], index, results: [{word, ok, ans?}], startedAt, source: "unit"|"wrongbook"|"custom" }` | 学生页 | 学生页（中途退出恢复） |
| `dict.wrongbook` | 错词本：`{ [wordKey]: { word, tip?, meaning?, subject, wrongCount, lastWrongAt } }`，wordKey = subject + ":" + word | 学生页 | 两页 |
| `dict.custom.banks` | 自定义词库（P0，用户提出的核心需求）：`[{ id, name, words: string[] }]`，上限 200 词/库 | 家长页 | 学生页 |

## 5. 前端数据访问层（接口契约）

前端不直接散写 localStorage，统一走 `js/store.js` 提供的模块（命名空间 `Store`）：

```js
// 词库读取（来自静态 JSON，内存缓存）
Store.banks.load()                          // => Promise<WordBank>  加载并校验词库
Store.banks.pick(versionId, gradeId, subjectId, unitId)  // => { unit, words[] }  按四级取单元词
Store.banks.list()                          // => { versions[] }  供选择器渲染

// 家长配置
Store.config.get() / Store.config.set(partial)     // 播报设置
Store.selection.get() / Store.selection.set(sel)   // 词库选择

// 默写会话
Store.session.get() / Store.session.set(s) / Store.session.clear()
Store.wrongbook.add(wordEntry, subject)     // 错词入本（wrongCount +1）
Store.wrongbook.list(subject?)              // => WrongEntry[]
Store.wrongbook.remove(wordKey)

// 判分（纯函数，可单测）
Store.judge.equals(input, word)             // 语文：严格相等后 trim；英语：忽略大小写、trim
```

判分规则约定：语文 `trim(input) === word`；英语 `trim(input).toLowerCase() === word.toLowerCase()`。多音字、形近字暂不模糊匹配（P1 可考虑"差一字也算错但标记疑似"）。

## 6. 语音播报层（接口契约）

`js/tts.js`，统一封装，替换 TTS 实现时不影响业务代码：

```js
TTS.speak({ text, rate = 0.9, lang = "zh-CN", onEnd })   // 播一个词
TTS.speakSequence(items, { rate, repeat, gapSec, onEnd }) // 按 repeat/gapSec 播整组
TTS.stop() / TTS.pause() / TTS.resume()
TTS.supported()   // => boolean，false 时 UI 提示"当前浏览器不支持语音播报"
```

浏览器自动播放限制：学生页第一次播报必须由用户手势触发（"开始"按钮），这点设计稿已符合。

## 7. 边界与安全

- 无网络请求即无注入面；自定义词库内容只做纯文本展示，渲染一律走 `textContent`，禁 `innerHTML` 拼用户输入。
- localStorage 读写包 try/catch（隐私模式可能抛错），失败降级为内存态。
- 词库 JSON 校验失败时前端降级用内置兜底单元（设计稿里那 8 个词），保证学生端永远能跑。
- 存储迁移：加载时校验 `dict.parent.selection` 的四级 id 是否仍存在于词库，失效则自动重置为默认选择（如词库升级、自定义词库被删除后），不允许把用户留在失效的"内置示范词库"选中态上（测试回归发现的建议级问题，由 `Store` 层统一处理）。
